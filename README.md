# ShopEase – E-commerce Product Showcase

## About
ShopEase is a responsive e-commerce product showcase website built using HTML, CSS, and JavaScript.

## Features
- Responsive design for desktop and mobile
- Product cards with images and prices
- Product search
- Category filters
- Add to cart functionality
- Cart item counter
- Total price calculation

## Technologies Used
- HTML5
- CSS3
- JavaScript
